# 商业财产保险理赔查勘与定损审核工作台

面向理赔员、专家与主管的商业财产险查勘工作台，覆盖损失科目、修复报价、残值、责任比例、准备金会签、争议项、附件版本和审计时间线。

## 技术栈

Angular + Angular Material + NgRx + Angular Router + HttpClient + RxJS + Angular CLI + TypeScript

## 本地运行

```bash
npm install
npm run start
```

访问 `http://localhost:62046`。

## 核心工作流

- 按案件和损失科目录入查勘事实、照片、报告与保单摘录。
- 调整修复报价时强制填写理由，并保留前后差异。
- 准备金按金额与风险阈值触发多级会签，可退回补件。
- 对比赔付方案、定位争议项、上传附件版本并导出完整审计记录。

## 授权事实模型（会签不再只看角色名称）

报价版本、会签记录和角色权限台账接成一条授权事实链：

- **角色权限台账**（`src/app/core/ledger.ts`）：职责（dutyId）挂权限与会签阈值，任命是只增的授予/撤销事件流，支持同岗多人同时在岗；每次换岗台账版本 +1。
- **报价提交**：写入时冻结操作者、当时职责和台账版本（`DutySnapshot`），新报价必须由当前具备报价职责的人提交。
- **会签处理**：审批人必须按**当前职责**在岗、达到档位阈值，且**未经手**该准备金下任一损失科目的报价（报价/审批同岗直接拦截）。
- **职责变化**：换岗后未完成会签立即按新台账重算（标注重算说明）；已签步骤保留当时冻结的依据，不回滚、不改写。
- **同档并发**：两个终端同时提交同档位时，服务端在途锁保证**先到结果生效**，后到返回 409。
- **写入失败恢复**：每个写请求带请求号（requestId），503 后凭同一请求号重试，已成功的请求幂等回放，不产生重复版本/重复会签。
- **旧数据升级**：缺少职责记录的历史报价/会签标记为 `dutyMissing`/`basisMissing`（`factsIncomplete`），补录前不放行会签；在审批页补录人员与当时职责后授权链才闭合。

侧栏可切换当前操作者（模拟不同终端/换岗），审批页提供"职责变更演练"和"两终端同时提交"。逻辑断言：`npm run test:auth`。
